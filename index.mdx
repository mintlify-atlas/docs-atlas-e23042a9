MsProject2019 Agent Kit is a PowerShell toolkit that lets Codex and other AI agents drive Microsoft Project 2019 on Windows without manual intervention. Agents can create schedules from a JSON plan, edit existing `.mpp` files by task UniqueID, verify the saved result, and export pixel-perfect PNG images of the full task table and Gantt chart — all without screen scrolling, VBA macros, or Python dependencies.

## How it works

The kit combines three automation layers, each with a specific role:

<Steps>
  <Step title="Prepare a JSON plan">
    Describe your tasks, durations, dependencies, and start date in a simple JSON file. The kit validates the structure — including cycle detection and type checks — before touching Project.
  </Step>
  <Step title="Create or edit a .mpp file">
    `Project-Codex.ps1` imports the plan via bulk XML (the fast default) or creates tasks one-by-one via COM. For edits, it copies the source file first so the original is never touched.
  </Step>
  <Step title="Verify the result">
    After saving, the script closes the file and reopens it in read-only mode, comparing all persisted fields against the expected snapshot. A `PASS` report is written to JSON.
  </Step>
  <Step title="Export and review">
    `Export-ProjectImage.ps1` opens a rendering copy, selects the requested tasks, calls Project's native GIF exporter, and converts the GIF to a pixel-identical PNG. Review the image once; no scroll-based screen capture required.
  </Step>
</Steps>
